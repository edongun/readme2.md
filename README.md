# League of Legends 라인별 TCI 모델 구현

## 1. 연구 목적

본 연구는 League of Legends 경기 데이터를 이용하여 네 라인별 지도학습 모델을 만들고 소환사별 TCI를 계산하는 것을 목적으로 한다. 기초 모델은 같은 시점의 팀 전체 골드 차이를 예측하고, TCI 산출 모델은 15분 라인 지표로 경기 마지막 시점의 같은 라인 골드 차이를 예측한다.

분석 대상은 TOP, JUNGLE, MIDDLE, BOTTOM의 네 라인이다. 각 라인에 대해 별도의 모델을 구성하며, BOTTOM은 원딜과 서포터에 해당하는 `BOTTOM`과 `UTILITY`의 값을 합산한다.

입력 데이터와 정답을 함께 사용하므로 본 연구의 모델링 방법은 지도학습에 해당한다.

## 2. 분석 데이터

- 분석 기간: 2025년 1월 8일~4월 7일, 한국 시간
- 분석 대상: 솔로랭크 중 20분 이상 진행되고 필요한 포지션 정보가 있는 36,912경기
- 학습용: 29,429경기
- 검증용: 7,483경기

학습 데이터는 모델의 가중치를 구하는 데 사용하고, 검증 데이터는 학습에 사용하지 않은 경기에서 예측 성능을 평가하는 데 사용한다.

동일한 경기의 여러 시점이 학습 데이터와 검증 데이터에 나누어 포함되지 않도록 경기 ID를 기준으로 분리하였다.

전체 38,075개 match/timeline 경기 ID가 서로 일치했다. 분석 조건을 통과한 경기는 36,912개이다. 나머지 1,163개는 분석 대상 큐가 아니거나 지정한 날짜 범위를 벗어나 제외된 경기이다.

## 3. 변수 설정

### 3.1 입력 피처

| 입력 | 뜻 |
|---|---|
| 경험치 차이 | 블루 팀 해당 라인의 경험치 − 레드 팀 해당 라인의 경험치 |
| CS 차이 | 블루 팀 해당 라인의 미니언·정글 몬스터 처치 수 − 레드 팀 해당 라인의 처치 수 |
| 챔피언 피해량 차이 | 블루 팀 해당 라인의 챔피언 대상 피해량 − 레드 팀 해당 라인의 피해량 |

입력은 상대와의 **누적 격차** 방식으로 통일하였다. BOTTOM은 각 팀 원딜과 서포터의 값을 합산한 후 차이를 계산하였다.

경험치는 성장 정도를, CS는 미니언과 정글 몬스터를 처치하며 자원을 확보한 정도를, 챔피언 피해량은 교전 기여를 나타내는 지표로 보았다. 세 지표는 타임라인에서 경기 중 시점별로 확인할 수 있고 네 라인에 같은 기준으로 적용할 수 있어 후보로 선정하였다. 10분·15분·20분 시점을 따로 비교했을 때, 챔피언 피해량을 추가한 모델의 검증 오차가 네 라인 모두에서 같거나 낮았다. 다만 개선 폭은 라인과 시점에 따라 달랐고, 이 비교만으로 피처의 중요도가 확정되는 것은 아니다.

### 3.2 타깃 변수

**정답 = 블루 팀 5명의 골드 합계 − 레드 팀 5명의 골드 합계**

입력은 한 라인의 기록이고, 타깃은 팀 전체의 골드 차이이다. 두 값은 동일한 시점을 기준으로 계산하였다. 따라서 본 모델은 미래의 골드나 최종 승패를 직접 예측하는 모델과는 구분된다.

타깃에 사용한 골드는 입력 피처에서 제외하여 자기 참조를 방지하였다.

### 3.3 타깃 변수 선정 근거

타깃 후보를 평가하기 위해 경기 종료 시점의 세 가지 점수가 실제 승패와 얼마나 일치하는지 비교하였다.

| 비교한 점수 | 승패와 일치한 비율 |
|---|---:|
| 골드 차이 | 98.18% |
| 골드+데미지 차이 | 95.40% |
| 골드+경험치 차이 | 98.26% |

복합 점수는 단위가 다른 값의 영향을 조정하기 위해 학습 데이터의 평균과 표준편차로 표준화한 후 동일한 가중치로 합산하였다. 점수가 0 이상이면 블루 팀의 승리로 판단하였다.

골드+경험치의 일치율이 가장 높았으나, 골드 단독보다 맞힌 경기 수는 6건 많았으며 차이는 약 0.08%p였다. 본 연구에서는 골드 단독도 승패와 높은 일치율을 보였고, 복합 점수의 가중치를 추가로 설정하지 않아도 되며 골드 단위로 해석할 수 있다는 점을 고려하여 골드 차이를 기본 타깃으로 선택하였다. 골드 단독이 최고 정확도를 기록한 것은 아니며, 두 후보의 통계적 동등성을 검증한 것도 아니다.

위 수치는 경기 종료 후 점수와 승패를 비교한 결과이며, 분 단위 TCI 회귀 모델의 예측 정확도를 의미하지 않는다.

## 4. 모델링 방법

기본 모델은 **선형회귀**로 구성하였다. 선형회귀는 입력 피처에 각각 가중치를 곱하고 더하여 연속적인 수치를 예측하는 방법이다.

**예측한 팀 골드 차이 = 경험치 차이 × 가중치 1 + CS 차이 × 가중치 2 + 챔피언 피해량 차이 × 가중치 3 + 기본값**

가중치는 예측값과 실제 골드 차이 사이의 제곱오차 합이 작아지도록 학습하였다. 입력 피처는 학습 데이터의 평균과 표준편차를 이용하여 표준화하고, 검증 데이터에도 동일한 기준을 적용하였다.

라인별로 별도의 모델을 학습하여 경험치·CS·챔피언 피해량 격차와 팀 골드 격차 사이의 관계를 추정하였다. 이는 예측 관계를 분석하는 것이며, 특정 라인이 팀의 우위를 직접 만들어 냈다는 인과관계를 의미하지 않는다.

## 5. 분석 결과

경험치, CS, 챔피언 피해량을 입력으로 사용한 선형회귀의 성능을 검증 경기의 분 단위 기록에서 평가하였다. 평가지표는 예측값과 실제값 사이의 절대 오차를 평균한 평균 절대 오차(MAE)를 사용하였다.

| 라인 | 예측값과 실제 골드 차이 사이의 평균 절대 오차 |
|---|---:|
| TOP | 약 2,130골드 |
| JUNGLE | 약 1,835골드 |
| MIDDLE | 약 2,108골드 |
| BOTTOM | 약 1,914골드 |

평균 절대 오차가 2,000골드인 경우, 예측한 팀 골드 차이가 실제 차이에서 평균적으로 약 2,000골드 벗어났음을 의미한다.

입력 피처를 사용하지 않고 학습 데이터의 평균 골드 차이만 예측하는 기준 모델의 오차는 약 2,536골드였다. 네 라인 모두 기준 모델보다 낮은 오차를 보였다.

이번 분석 조건에서는 JUNGLE 모델의 오차가 가장 작았다. 다만 이 결과를 정글의 인과적 기여도나 정글 이용자의 실력이 가장 높다는 의미로 해석할 수는 없다.

피처 조합 비교에서는 경험치와 CS만 사용한 모델에 챔피언 피해량을 추가했을 때, 분 단위 기록 전체를 합친 평가에서 오차가 소폭 낮아졌다. 또 10분·15분·20분 시점의 별도 비교에서도 피해량을 추가한 모델의 오차가 네 라인 모두에서 같거나 낮았다. 이에 현재 결과물은 세 피처를 모두 사용하는 모델로 구성하였다. 다만 검증 분할을 한 번 사용한 결과이므로, 피해량의 효과가 다른 데이터에서도 똑같이 나타나는지는 추가 검증이 필요하다.

### 5.1 TCI 점수 모델의 추가 결과

개인·라인 점수 산출을 위해 15분 피처로 **경기 마지막 시점의 같은 라인 골드 격차**를 예측하는 별도 모델도 실행하였다. 아래 MAE는 경기 ID 기준 5겹 교차검증의 바깥쪽 예측(OOF)으로 계산했으며, 모든 라인에서 학습 자료 평균만 예측한 기준 모델보다 낮았다.

| 라인 | TCI 모델 MAE | 기준 모델 MAE |
|---|---:|---:|
| TOP | 약 1,756골드 | 약 2,391골드 |
| JUNGLE | 약 1,862골드 | 약 2,388골드 |
| MIDDLE | 약 1,759골드 | 약 2,176골드 |
| BOTTOM | 약 2,740골드 | 약 3,419골드 |

이 표의 타깃은 앞 표의 **팀 전체 골드 격차**와 다르므로 두 결과를 직접 비교하지 않는다. BOTTOM 타깃과 피처는 원딜·서포터 듀오를 합산한 값이다.

## 6. TCI 활용 방안

현재 모델의 예측값은 **팀 전체 골드 격차**이다. 따라서 이 값을 그대로 한 소환사의 TCI 점수라고 부를 수는 없다. 팀 골드 격차에는 해당 라인뿐 아니라 다른 라인과 팀 전체 상황도 함께 반영되기 때문이다.

### 6.1 소환사 TCI 계산 방법

개인별 경기 기록을 비교하는 TCI 계산 스크립트를 작성하고 전체 분석 자료에 실행하였다. 이 모델은 경기별 15분 라인 지표로 마지막 타임라인의 같은 라인 골드 격차를 예측한다.

1. 각 경기에서 15분 시점의 라인별 경험치·CS·챔피언 피해량 격차를 입력으로 사용한다.
2. 정답은 경기 마지막 타임라인의 해당 라인 골드 격차로 둔다. 예를 들어 TOP은 블루 TOP과 레드 TOP의 골드 차이를 사용한다. BOTTOM은 각 팀의 원딜과 서포터 골드를 합산한 뒤 차이를 계산한다.
3. 네 라인별로 별도의 지도학습 회귀 모델을 학습한다. 참가자 ID는 예측 입력으로 사용하지 않고, 여러 경기 결과를 같은 소환사별로 모으는 데만 사용한다.
4. 모델이 각 경기에서 예측한 라인별 최종 골드 격차를 소환사별로 평균한다.
5. 같은 라인과 패치에 속한 소환사들의 평균 및 표준편차를 기준으로 점수를 바꾼다.

**TCI = 50 + 10 × (소환사의 경기별 예측 골드 격차 평균 − 같은 라인·패치 평균) ÷ 같은 라인·패치 표준편차**

이 방식에서 50점은 같은 라인·패치의 평균 수준이고, 60점은 평균보다 표준편차 하나 높은 수준이다. 점수는 같은 라인과 패치 안에서 비교한다. BOTTOM 점수는 원딜과 서포터가 함께 만든 공동 점수이며, 두 사람의 개인 점수를 따로 계산하려면 별도의 피처와 모델이 필요하다.

경기 ID를 기준으로 5겹을 나누어 각 경기가 자신을 포함하지 않은 모델에서 예측되도록 했다. 이렇게 얻은 경기별 예측값을 소환사별로 평균하고 같은 라인·패치 안에서 표준화했다. 전체 36,912경기에서 네 라인별 147,648개의 경기 예측을 만들었고, 라인·패치별 소환사 점수 행은 62,410개 생성되었다.

기본 입력 폴더는 `C:\Users\user\Desktop\보관함\match_data`이고 결과는 `C:\Users\user\Desktop\보관함\데이터용\line_tci_scores`에 저장된다. 전체 분석은 다음 스크립트로 수행할 수 있다.

```bash
python calculate_line_tci.py
```

주요 결과 파일은 `line_tci_player_scores.csv`(소환사별 TCI), `line_tci_metrics.csv`(라인별 교차검증 오차), `line_tci_oof_predictions.csv`(경기별 검증 예측)이다. 점수는 0~100으로 제한되지 않는 표준화 점수이며, 50은 해당 라인·패치 평균이다. 이번 실행의 점수 범위는 약 -5.35~100.74였다. 점수 CSV에는 소환사 식별자가 포함되므로 공개 저장소에 올릴 때는 삭제하거나 익명화해야 한다.

이번 실행에서 소환사·라인·패치 조합별 경기 수의 중앙값은 2경기였고, 45.9%는 한 경기만 있었다. 5경기 이상 있는 조합은 26.6%였다. 따라서 경기 수가 적은 소환사의 점수는 변동이 클 수 있다. 개인 간 비교에서는 우선 5경기 이상인 점수를 확인하고, 경기 수를 함께 고려해야 한다.

## 7. 한계

- 팀 골드 차이는 팀 전체의 결과이므로 한 라인의 개인 기여를 완전히 분리하지 못한다.
- 챔피언, 상대 수준, 패치 등에 따라 결과가 달라질 수 있다.
- 이번 결과는 한 번 나눈 확인용 경기에서 얻은 결과이며, 긴 경기는 더 많은 분 단위 기록으로 반영됐다.
- 현재 세 입력은 간단한 기준 모델용이다. 모든 라인의 최적 피처를 찾았다는 뜻은 아니다.
- 현재 TCI는 동일한 분석 자료의 5겹 교차검증 예측을 집계한 상대 점수이다. 다른 기간·패치의 경기에서도 소환사 순위가 재현되는지는 별도로 검증하지 않았다.

## 8. 결론

본 연구에서는 36,912경기의 데이터를 이용하여 네 라인별 팀 골드 격차 예측 모델과 라인별 최종 골드 격차 기반의 TCI 산출 모델을 구성하였다. 두 모델 모두 모든 라인에서 기준 모델보다 낮은 검증 오차를 보였다. 소환사별 TCI는 라인·패치별 상대 점수로 계산하였으며, 경기 수가 적은 소환사의 점수는 신뢰도가 낮을 수 있다.

이 점수는 여러 경기에서의 상대적 수행 수준을 비교하는 참고값이며, 절대적인 실력이나 인과적 기여도로 해석하지 않는다. 향후에는 최소 경기 수 기준과 새 기간의 독립 검증을 추가할 필요가 있다.
